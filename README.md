# Luciano Magrini - Portafolio Artístico Personal & Espectáculo MPV

Sitio web oficial y portafolio personal del violinista **Luciano Magrini**, desarrollado con HTML5 semántico, CSS3 Vanilla y JavaScript moderno, optimizado para visualización en teléfonos móviles, computadoras y listo para alojarse en **GitHub Pages**.

---

## 🚀 Cómo Abrir la Página Localmente

Solo debes hacer **doble clic en el archivo `start.bat`**:
1. Se abrirá automáticamente tu navegador web en `http://localhost:8080/`.
2. Se iniciará el servidor local para que todas las fotos y videos se carguen de inmediato.
3. Para cerrarlo cuando termines, simplemente cierra la ventana negra de la consola.

---

## ✨ Características Principales

1. **Redacción en Primera Persona**:
   - Todo el contenido está narrado directamente por Luciano: su visión artística, su trayectoria, su show colectivo, su rider técnico y sus vías de contacto directo.

2. **Diseño 100% Responsivo para Teléfonos Móviles**:
   - Adaptado para cualquier tamaño de pantalla (smartphones compactos de 320px, iPhones, Android y tablets).
   - Menú móvil desplegable suave con acceso directo a cada sección.
   - Botón táctil flotante de WhatsApp siempre accesible para contrataciones inmediatas.
   - Elementos interactivos con áreas táctiles generosas para evitar pulsaciones erróneas con los dedos.

3. **Estética Fiel al Dossier Oficial**:
   - Modo oscuro cinematográfico (`#070709`) con iluminación azul cenital teatral (`#38bdf8`) y detalles en blanco y dorado.
   - Tipografía refinada: firmas caligráficas en *Alex Brush*, títulos solemnes en *Cinzel* y lectura contemporánea en *Montserrat*.

4. **Carretes de Fotos estilo Instagram**:
   - 12 publicaciones interactivas para cada concierto y locación real.
   - **La foto de portada siempre es la primera** de cada carrete con distintivo `★ Portada`.
   - Navegación táctil (swipe), flechas prev/next y barra de puntos interactivos.
   - Botón de Like y animación de corazón flotante al hacer doble toque en la foto.
   - Visor **Lightbox en pantalla completa** con navegación por flechas y teclado.
   - Filtros dinámicos por tipo de evento.

5. **Reproductor y Grilla de Videos de YouTube**:
   - Integra los **10 videos oficiales** de `Enlaces para usar.txt`, incluyendo el *Trailer Oficial de Música Para Ver (MPV)*.
   - Modal cinematográfico para reproducción instantánea en alta definición.

6. **Rider Técnico & Contacto**:
   - Plano escénico interactivo con los requerimientos de escenario, pantalla y sonido para productores teatrales.
   - Contacto directo por WhatsApp con mensaje preconfigurado, Instagram, YouTube, Email y enlace de descarga directa del Dossier Oficial en PDF.

## 🌐 Subir a GitHub Pages (Cuando decidas publicarlo)

El sitio utiliza rutas relativas, por lo que funcionará automáticamente en cualquier repositorio de GitHub:

1. Inicia Git en la carpeta si no lo has hecho:
   ```bash
   git init
   git add .
   git commit -m "Portafolio profesional Luciano Magrini"
   git branch -M main
   ```
2. Conéctalo a tu repositorio remoto de GitHub:
   ```bash
   git remote add origin https://github.com/TU-USUARIO/TU-REPOSITORIO.git
   git push -u origin main
   ```
3. En GitHub, ve a **Settings** > **Pages** > selecciona rama `main` y carpeta `/ (root)`.
